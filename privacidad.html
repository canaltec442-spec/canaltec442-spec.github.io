Política de privacidad

Última actualización: 16 de noviembre de 2026.

Esta política describe cómo la aplicación Canal Tec Publicador (en adelante, "la aplicación") trata la información. La aplicación es una herramienta de uso exclusivo del dueño del canal de YouTube "Canal Tec" para subir y programar sus propios videos.

Servicios de API de YouTube

La aplicación usa los Servicios de API de YouTube. Al usarla, aceptas los Términos del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Qué información se usa

  • El acceso autorizado (token OAuth) a la cuenta de YouTube del propio canal, para subir videos, definir su título, descripción, miniatura y estado de publicación.
  • Datos públicos de YouTube (por ejemplo, videos populares por categoría) para investigar tendencias.

La aplicación no recopila, almacena ni comparte datos personales de espectadores ni de otros usuarios de YouTube.

Almacenamiento y seguridad

El token de acceso se guarda en un servidor privado del dueño del canal, en un archivo con permisos restringidos, y nunca se comparte con terceros. No se venden ni se transfieren datos.

Cómo revocar el acceso

El acceso puede revocarse en cualquier momento desde la página de seguridad de la cuenta de Google: myaccount.google.com/permissions.
